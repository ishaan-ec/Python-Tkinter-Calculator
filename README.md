# Python Tkinter Calculator

A simple desktop calculator built using Python and Tkinter. This project was created as a beginner GUI project to learn how graphical user interfaces work in Python.

## Features

- Basic arithmetic operations (+, -, *, /)
- Bracket support for expressions
- Displays the complete expression before calculating
- Backspace button to remove the last character
- Clear button to clear the display
- Simple graphical user interface

## Tech Stack

- Python
- Tkinter

## How to Use

1. Download `Calculator.exe` from the Releases section.
2. Run the executable.
3. Enter your expression using the calculator buttons.
4. Press `=` to calculate the result.
5. Use `C` to clear or `⌫` to remove the last character.

## Project Purpose

This project helped me learn GUI development in Python, event handling, button functionality and working with expressions through Tkinter.
